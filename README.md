# 🌱 Agro Guide

**AI-powered agricultural assistance and farm-management platform.**

Agro Guide is a farmer-centric web application intended to help farmers manage farm information and access decision-support guidance for crop selection, irrigation, soil management, crop problems, and weather.

## Core modules
- Farmer registration and login
- Farmer profile and farm/plot management
- Personalized dashboard
- ML-based crop recommendation
- Irrigation and soil/fertilizer assistance
- Pest and disease problem assistance
- Weather information
- Cultivation guidance
- Recommendation and farm-activity history

## Technology stack
- Frontend: React, Vite, Tailwind CSS
- Backend: Python, FastAPI
- Database: PostgreSQL
- Machine learning: pandas, NumPy, scikit-learn, joblib
- Version control: Git and GitHub

## Repository structure
- `frontend/` — React application
- `backend/` — FastAPI application, APIs, database integration
- `machine-learning/` — datasets, notebooks, training and inference code
- `documentation/` — proposal, architecture, diagrams and screenshots
